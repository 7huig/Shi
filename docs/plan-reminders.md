# 分类目标、静态提醒与热力图

[← 返回 README](../README.md)

## 为什么做

时间记录器最容易变成「记不全的自责工具」：空白块写着「未记录」，旁边还有「+ 补记」，用户一整天都在被提醒自己漏了多少。0.4.0 先把这些催促性文案拿掉，再用用户主动开启的分类计划，把「想记的事」轻轻放到首页。

所有提示都在应用内静态展示：不申请通知权限、不响铃、不弹系统通知，也不做与其他用户的比较。

## 入口

从顶栏「⋮ → 分类管理」进入分类列表，每行右侧的目标与提醒图标打开该分类的计划弹窗；有配置时图标显示为主题色。颜色在分类编辑弹窗里默认收起，需要改色时再展开，避免挤占计划弹窗的空间。

每个分类可以同时开启：

- **每日时长**：1–1440 分钟，父分类自动包含子分类的记录；
- **固定时间**：一天可以设多个时间点，每个时间点有独立事项名和 0–180 分钟的提前提示，默认准时提醒；
- **间隔待办**：5–10080 分钟的间隔 + 待办名；只根据该分类的记录自动刷新下一次时间，没有手动完成入口，跨天也成立；
- **热力图**：在時計页顶部展示该分类最近 24 周的每日用时。

四块配置相互独立。全部关闭时删除该分类的计划行和固定时间，不留空记录。

## 首页静态提示

今日提示在时间轴上方，固定最多两行：第一行只放每日时长，第二行放固定时间和间隔待办。每行卡片少时整体居中，超出屏幕宽度时横向滚动；不显示「今日提示 N 件」标题，不显示卡片类型行，也不显示卡片底部的时间计算行。三种卡片共用同一个两行模板（分类名 / 次要信息），文字水平、垂直居中；每日时长的进度条作为底部叠层，不参与文字排版。卡片高度 48dp，尽量把空间让给时间轴。日期右侧没有日历图标，点日期标题仍可切换日期。

卡片按「先到期、后未到期」排序：

| 类型 | 展示 | 如何更新 |
| --- | --- | --- |
| 每日时长 | 分类名、今日已记录 / 目标；底部细进度条 | 记录自然推进，不需要额外操作 |
| 固定时间 | 分类名 + 今天 HH:mm；到期时用分类色强调 | 点卡片记一笔，记录落在该时间点到下一个固定时间之间即算完成 |
| 间隔待办 | 分类名 + 「该做了」或「下次 HH:mm / 明天 HH:mm」；没有手动完成按钮 | 给该分类记一笔，下一次时间自动推到记录结束 + 间隔 |

点卡片本身会用该分类预填最近 30 分钟的记录，避免从提示跳到空白表单。

## 数据

Room v11 用两张表保存计划：

```text
category_plan
categoryId (PK) · heatmapEnabled · dailyGoalMinutes
intervalMinutes (0 = off) · intervalLabel
nextReminderAt · updatedAt

fixed_time
id (PK) · categoryId (FK CASCADE) · minuteOfDay (0..1439)
label · leadMinutes
```

一个分类最多 8 个固定时间，按分钟数升序展示；同一个分钟数只能出现一次。保存时整体替换该分类的固定时间行，旧数据里唯一的固定时间会在迁移时原样搬进新表。v10 会把 v8 / v9 期间写入的高饱和分类色映射回低饱和节气色；v11 删除手动完成历史列。

保存规则：

- 间隔首次开启、修改间隔、或旧的 `nextReminderAt` 为空时，从当前时间重新计时；
- 只改事项名、目标或固定时间，不重置下一次提醒；
- 关闭间隔时清空下一次时间；
- 删除分类时计划与固定时间一起删除，不需要额外清理。

首页计算间隔待办时会读取**所有历史记录**（包括昨天），只统计本次间隔开始之后的记录：

```text
本次间隔开始 = nextReminderAt - interval
下一次 = 本次间隔开始后的最近记录结束时间 + interval
```

若这个周期内没有记录，则沿用保存时写入的 `nextReminderAt`。所以卡片只会在正常记录时间块后自动刷新，跨天后仍然按真实活动时间计算，而不是每天零点重置；刚开启计划时，更早的记录不会立刻把下一次提醒提前。间隔待办没有手动完成入口，也不需要保存完成历史。

备份 schema 升到 5，`plans[].fixedTimes` 保存多个固定时间与提前量；读取 schema 1 / 2 / 3 / 4 时兼容旧文件（schema 3 的单个固定时间字段会读成一条提前 0 分钟的记录，旧版手动完成字段会被忽略）。覆盖导入恢复计划，合并导入只给新分类补计划，不覆盖本机已有配置。

## 热力图

`CategoryHeatmapBuilder` 只为 `heatmapEnabled = true` 的分类生成数据，默认 168 天：

- 跨天事件按本地日历拆到前后两天；
- 父分类的每天累加整棵子树，与统计页「分类含子分类」口径一致；
- 颜色按该分类窗口内的每日最大值归一化，0 记录显示为空轨道色；
- 网格 7 行 × 24 列，置顶在统计页并居中，按分类列出，显示总时长与有记录天数。

## 边界

- 每个分类最多一条每日时长、8 个固定时间、一条间隔待办；需要更多提醒可以拆成子分类。
- 间隔待办只根据记录自动刷新，没有手动完成入口，也不会自动生成时间记录；需要计时仍走正常记录流程。
- 提示只在应用打开时刷新，没有后台唤醒、WorkManager 或系统通知。
- 固定时间的「已记录」只看该时间点到下一个固定时间之间的记录；晚上的一次记录不会把早上的所有事项都标成已完成。
